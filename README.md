# ✊ Rock Paper Scissors

A simple command-line Rock-Paper-Scissors game built using Python. Play against the computer, which randomly selects rock, paper, or scissors.

## 🎮 Features

- Play against a computer opponent.
- Random computer choices using Python's "random" module.
- Input validation to prevent invalid choices.
- Automatic winner detection.
- Option to play multiple rounds.
- Simple and beginner-friendly code structure.

## 🛠️ Technologies Used

- **Language:** Python 3
- **Module:** "random" (Python standard library)

## 📖 How to Play

1. Run the Python file.
2. Enter `rock`, `paper`, or `scissors`.
3. The computer randomly chooses an option.
4. The game announces the winner.
5. Choose whether to play another round.

### Winning Rules

| Your Choice | Computer Choice | Result |
|---|---|---|
| Rock | Scissors | You win |
| Paper | Rock | You win |
| Scissors | Paper | You win |
| Same choices | Same choices | Tie |
